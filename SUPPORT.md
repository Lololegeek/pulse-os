# Support

PulseOS is currently an alpha community project, not a commercial support product.

## Before opening an issue

Run:

```bash
pulseosctl doctor
```

and collect the relevant output. Also check existing issues for the same GPU, game, kernel or installer problem.

## Bug reports

Use the GitHub bug report form and include hardware, PulseOS version, logs and exact reproduction steps.

## Performance regressions

Use the dedicated performance-regression form. Include before/after measurements from the same machine rather than a comparison between unrelated systems.

## Game compatibility

When a Windows game fails under Proton, first determine whether the issue also occurs on a mainstream current Proton/Linux setup. PulseOS should fix OS-level regressions, but game-specific Proton bugs may belong upstream.

## Security

Follow [SECURITY.md](SECURITY.md). Do not publish sensitive vulnerability details in normal issues.
